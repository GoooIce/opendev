# PRD：农业产业大数据指挥仓系统（现代化 Demo）

> 版本：v0.2 | 日期：2026-04-16 | 状态：已确认，准备开发

---

## 一、项目概述

### 1.1 背景

基于一个五年前的"农业产业大数据指挥舱"静态模板（jQuery + ECharts + Canvas），运用现代 Web 技术栈重新设计并实现一个面向政府决策者的农业大数据可视化大屏 Demo。

### 1.2 目标

| 维度 | 目标 |
|------|------|
| **视觉** | 现代科技感 + 农业主题融合，避免廉价感配色 |
| **数据** | 基于真实行业报告（2020-2025），展示决策者关心的核心指标 |
| **交互** | 地图可交互、数据可下钻、AI 辅助分析 |
| **适配** | 以 19:6 超宽屏为基准，向下兼容 4:3，向上兼容 21:9 |
| **技术** | Next.js 15 + Bun + ECharts 5 + MapLibre GL + Vercel AI SDK |

### 1.3 与原系统对比

| 维度 | 原系统（5年前） | 新系统 |
|------|----------------|--------|
| 技术栈 | jQuery + 静态 HTML | Next.js 15 + React 19 + TypeScript |
| 地图 | 静态图片 + CSS 定位 | MapLibre GL + Deck.gl 实时交互地图 |
| 图表 | ECharts 基础图表 | ECharts 5 + 动态数据驱动 |
| 数据 | 硬编码假数据 | 基于行业报告的仿真数据 |
| AI | 无 | LLM 智能分析助手（自然语言查询数据） |
| 适配 | vw 单位粗放适配 | vw/vh + clamp() + Container Queries + Scale 兜底 |
| 配色 | 纯科技蓝 `#0efcff` | 农业+科技融合色系（翠谷金穗方案） |
| 主题 | 茶叶种植单一场景 | 宏观农业全产业链（不保留原茶叶场景） |

## 五、视觉设计规范

### 5.1 配色方案：翠谷金穗

```css
:root {
  /* 背景 */
  --bg-primary: #0A1628;      /* 深海蓝底 */
  --bg-secondary: #0D2137;    /* 卡片底色 */
  --bg-card: rgba(13, 33, 55, 0.85);

  /* 主色 - 生命绿 */
  --color-primary: #1DB954;
  --color-primary-light: #2ECC71;
  --color-primary-glow: rgba(29, 185, 84, 0.6);

  /* 辅助色 - 丰收金 */
  --color-accent: #F0A500;
  --color-accent-dark: #C48800;

  /* 语义色 */
  --color-danger: #E74C3C;    /* 预警 */
  --color-info: #3498DB;      /* 信息 */
  --color-success: #1DB954;   /* 正向 */

  /* 文字 */
  --text-primary: #E8ECF1;    /* 标题、核心数值 */
  --text-secondary: #8B9BB4;  /* 辅助说明 */

  /* 边框 */
  --border-color: rgba(29, 185, 84, 0.2);
  --border-glow: rgba(29, 185, 84, 0.4);
}
```

**配色原则：**
- 背景深蓝 → 科技感基底
- 绿色主色 → 农业/生长/生态
- 金色辅助 → 丰收/高端/强调
- 红色仅用于预警/异常 → 不大面积使用
- 避免紫色系、纯黄色、荧光色

### 5.2 字号规范（1920x1080 基准）

| 元素 | 字号 | 字重 | 颜色 |
|------|------|------|------|
| 系统标题 | clamp(24px, 1.8vw, 42px) | 700 | --color-accent |
| 导航标签 | clamp(12px, 0.9vw, 18px) | 500 | --text-primary |
| KPI 核心数值 | clamp(28px, 3vw, 56px) | 700 | --text-primary 或 --color-accent |
| KPI 标题 | clamp(12px, 0.8vw, 18px) | 400 | --text-secondary |
| 卡片标题 | clamp(14px, 1vw, 24px) | 500 | --color-primary |
| 普通数据 | clamp(12px, 0.7vw, 16px) | 400 | --text-primary |
| 辅助文字 | clamp(10px, 0.6vw, 14px) | 400 | --text-secondary |

### 5.3 动效规范

| 场景 | 动效 | 时长 | 实现 |
|------|------|------|------|
| 数值入场 | 从 0 滚动到目标值 | 2s | JS countUp |
| 卡片入场 | 从透明淡入 + 轻微上移 | 0.5s | CSS transform + opacity |
| 地图飞线 | 粒子沿路径流动 | 持续 | Deck.gl |
| 数据更新 | 柱状图/折线平滑过渡 | 0.3s | ECharts transition |
| 预警触发 | 边框红色脉动 + 图标闪烁 | 持续 | CSS animation |
| 日志滚动 | 新条目从顶部淡入滑下 | 0.3s | CSS transition |
| AI 面板展开 | 从右下角弹出展开 | 0.3s | CSS transform |

**动效禁忌：**
- 核心数值区域不抖动/旋转
- 背景粒子不超过 50 个
- 不使用弹跳/旋转等花哨动画
- 装饰边框不持续闪烁

## 六、屏幕适配策略

### 6.1 适配目标

| 比例 | 代表分辨率 | 策略 |
|------|-----------|------|
| **19:6**（基准） | 3840x1080 | 完整三栏布局，中央横排 4 KPI + 双图层地图 |
| 16:9 | 1920x1080 | 三栏布局，中央横排 4 KPI + 单图层地图 |
| 21:9 | 2560x1080 | 中央区域加宽，增加图表列数 |
| 4:3 | 1024x768 | 精简为 3 KPI + 地图全宽 + 底部图表 |

### 6.2 CSS 适配方案

```
布局骨架：vw/vh + CSS Grid
字体大小：clamp()（弹性范围）
组件响应：Container Queries（数据卡片、图表容器）
极端兜底：transform: scale()（JS 计算缩放比）
```

### 6.3 响应断点

```css
/* 超宽屏 19:6+ */
@media (min-aspect-ratio: 19/6) {
  .dashboard {
    grid-template-columns: 20vw 60vw 20vw;
  }
}

/* 标准宽屏 16:9 */
@media (min-aspect-ratio: 16/9) and (max-aspect-ratio: 19/6) {
  .dashboard {
    grid-template-columns: 22vw 1fr 22vw;
  }
}

/* 带鱼屏 21:9 */
@media (min-aspect-ratio: 21/9) {
  .dashboard {
    grid-template-columns: 18vw 1fr 18vw;
  }
}

/* 传统屏 4:3 */
@media (max-aspect-ratio: 4/3) {
  .dashboard {
    grid-template-columns: 1fr;
    grid-template-rows: auto;
  }
}
```

### 7.3 关键技术决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 地图库 | MapLibre GL + Deck.gl | 开源免费，API 兼容 Mapbox，矢量底图可定制 |
| 图表库 | ECharts 5 | 中文文档好，功能全，大屏场景生态成熟 |
| 样式方案 | Tailwind + CSS Variables | Tailwind 快速布局，CSS Variables 主题切换 |
| WebGPU | 暂不引入 | 覆盖率 70-75%，需 WebGL2 fallback，Demo 阶段不必要 |
| Bun 运行时 | 仅开发工具链 | 生产运行时延迟 246ms vs Node 20ms，不可接受 |
| 数据方案 | 静态 JSON + 定时刷新模拟 | Demo 不需要真实后端，用 setInterval 模拟实时 |

- **日志数据**：每 5-10 秒新增一条模拟记录
- **气象数据**：每 30 秒更新一次模拟数据

## 十、风险与约束

| 风险 | 级别 | 应对 |
|------|------|------|
| Mapbox API Token 需要申请 | 中 | 提前注册，或备选方案使用开源地图（如 MapLibre） |
| LLM API 成本（AI 助手） | 低 | Demo 阶段限流，或使用本地模型 |
| 仿真数据与真实数据差距 | 低 | 明确标注"演示数据"，数据趋势基于真实报告 |
| 超宽屏实机测试条件不足 | 中 | 浏览器 DevTools 模拟 + Scale 方案兜底 |
| 第三方库体积（Mapbox ~51MB） | 中 | 按需加载 + 预渲染 |
