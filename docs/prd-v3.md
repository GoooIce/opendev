# PRD：玉米氮高效高通量基因挖掘与应用平台（现代化 Demo）

> 版本：v0.3 | 日期：2026-04-19 | 状态：已确认，准备开发

---

## 一、项目概述

### 1.1 背景

在全球粮食安全与可持续农业的双重压力下，提高玉米氮利用效率（NUE）已成为现代农业科学研究的核心议题。传统基因挖掘存在**周期长、通量低、效率差**的瓶颈。本平台旨在构建一个集**多组学整合、高通量表型鉴定、生物信息学分析、CRISPR基因编辑与AI辅助决策**于一体的综合性研究平台，实现从海量数据中快速精准鉴定氮高效基因并应用于育种实践。

### 1.2 目标

| 维度 | 目标 |
|------|------|
| **科学** | 整合基因组/转录组/蛋白组/代谢组/表型组五维组学数据，构建氮代谢全景调控网络 |
| **技术** | 打破传统"基因型-表型"关联分析瓶颈，实现高通量自动化流水线 |
| **应用** | 挖掘具有重大育种价值的氮高效候选基因，支撑绿色超级玉米品种培育 |
| **交互** | 可视化展示基因挖掘全流程，支持自然语言查询基因功能与代谢通路 |
| **视觉** | 生物科技感 + 农业主题融合，突出分子机制可视化 |

### 1.3 与传统平台的对比

| 维度 | 传统基因挖掘平台 | 新平台 |
|------|------------------|--------|
| 组学维度 | 单一或二维组学 | 五维组学深度整合（基因组+转录组+蛋白组+代谢组+表型组） |
| 表型获取 | 人工测量，低通量 | 无人机遥感 + 自动化成像平台，日处理千株级 |
| 基因分析 | 单点GWAS/QTL | 多组学整合网络分析 + 机器学习预测模型 |
| 功能验证 | 周期长（6-12个月） | CRISPR/Cas9快速验证 + 温室加速表型 |
| AI能力 | 无或弱 | Agent驱动的基因筛选系统 + LLM知识问答 |
| 可视化 | 静态图表 | 交互式网络图 + 3D分子结构 + 动态通路动画 |
| 数据规模 | 百样本级 | 万样本级（中美自交系群体） |

## 四、功能模块详细设计

### 4.1 顶部导航栏（Header）

**功能：**
- 系统标题：「玉米氮高效高通量基因挖掘与应用平台」
- 导航标签：全景概览、多维组学、基因挖掘、表型鉴定、功能验证、AI智囊、文献中心
- **当前分析流程状态条**：显示正在运行的分析任务进度（如"RNA-seq比对中 78%"）
- 全屏切换 + 主题切换（深色科研模式 / 浅色论文模式）

**视觉：**
- 深色底（`--bg-primary`）+ DNA双螺旋装饰边框
- 标题居中，渐变绿金配色（`--color-primary` → `--color-accent`）
- 流程状态条采用脉冲动画表示活跃任务

### 4.2 KPI 核心指标区（Center Top）

**功能：**
- 4 个核心数字卡片：NUE综合指数、候选基因库规模、已验证基因数、表型通量
- 每个卡片包含：图标、核心数值、单位、同比/环比变化、迷你趋势线
- 数值从 0 滚动到目标值的入场动画（2s，缓动函数 easeOutExpo）

**交互：**
- 悬停展开详情面板：
  - NUE卡片 → 展开各品种NUE雷达图对比
  - 基因库卡片 → 展开按功能分类的基因饼图（转运/同化/信号/转录因子）
  - 验证基因卡片 → 展开基因卡片网格（点击跳转详情页）
  - 表型通量卡片 → 展开今日处理队列实时滚动

### 4.3 中央交互区域：玉米植株六维生物学过程图（Center Mid）—— **核心亮点**

这是整个平台的**视觉中心和交互核心**，对应图片右侧的玉米植株示意图。

**功能：**
- **中央主体**：高精度玉米植株矢量插图（根-茎-叶-穗完整形态）
- **六个过程节点**：环绕植株的圆形/椭圆形标注区域，分别对应六大生物学过程：
  - ① 根部区域：硝酸盐吸收（带膜转运蛋白动画）
  - ② 根部下方：根系生长响应（根系动态伸展动画）
  - ③ 穗部区域：低氮诱导开花（光周期路径示意）
  - ④ 叶片区域：氮素再动员（源-库转运箭头动画）
  - ⑤ 顶部茎叶：叶片扩展与分枝（分生组织活性示意）
  - ⑥ 茎秆下部：花青素合成（代谢通路节点闪烁）

**交互：**
- **悬停某个过程节点**：
  - 该节点放大发光（`scale(1.1)` + `box-shadow glow`）
  - 植株上对应部位高亮（如悬停①则根部高亮）
  - 显示 Tooltip：过程名称 + 关键基因数量 + 最新研究发现摘要
- **点击某个过程节点**：
  - 中央区域切换为该过程的**详细视图**：
    - 代谢通路图（KEGG风格，可缩放）
    - 参与基因列表（可排序、筛选）
    - 相关文献引用（自动抓取PubMed）
    - 多组学数据叠加（该通路基因的表达热图）
- **过程间连线**：动态贝塞尔曲线连接相关过程（如①→④表示吸收后转运），悬停显示调控关系描述
- **全局控制栏**：
  - 氮水平滑块（低氮 ←→ 适氮 ←→ 高氮）：实时更新所有过程的活性状态
  - 生育期选择器（苗期/拔节/抽雄/灌浆/成熟）：切换不同时期的重点关注过程
  - 图层开关：显示/隐藏基因名称/表达量/代谢物浓度

**技术实现：**
- 使用 **D3.js + SVG** 绘制静态结构和连线
- 使用 **CSS Animation + Canvas** 实现粒子流动效果（模拟物质转运）
- 使用 **WebGL（可选 Deck.gl）** 实现高性能粒子系统（如硝酸盐离子流）

  - "哪些基因同时出现在 GWAS 显著位点和低氮诱导的差异表达基因中？"

### 7.3 关键技术决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 植株图实现 | SVG + CSS Animation | 矢量无损缩放，DOM事件绑定简单，无需WebGL开销 |

| 向量数据库 | 开发阶段用内存FAISS，生产用Pinecone | Demo阶段不需要外部依赖，FAISS WASM可在浏览器运行 |
| 3D根系可视化 | 暂用2D投影，预留Three.js接口 | 降低首屏加载体积，后续可渐进增强 |
| 数据规模 | 前端模拟1247个基因元数据 + 100个GWAS位点 | 真实数据量过大，Demo取代表性子集 |

### 8.2 数据更新策略（模拟实时感）

- **KPI 数据**：页面加载时初始化，每 60 秒微调 ±0.5%（模拟新数据入库）
- **分析日志**：每 8-15 秒随机新增一条（类型轮询：测序/比对/关联/建模）
- **Agent 排名**：当用户调整筛选条件时实时重算（前端 debounce 300ms）
- **植株过程活性**：随氮水平滑块实时插值更新（无延迟）
- **网络图布局**：初始加载 1.5s 动画展开，之后静态（除非筛选变更）

## 附录 A：六大生物学过程详细说明（供开发参考）

### 过程① 硝酸盐吸收 (Nitrate Uptake)
- **关键基因**：ZmNRT1.1A, ZmNRT1.1B, ZmNRT1.2, ZmNRT2.1, ZmNRT2.2, ZmNAR2.1, ZmCLCa, ZmSLAC1, ZmCHL1
- **生物学意义**：根系从土壤中吸收硝酸盐的第一步，是氮利用效率的限速步骤之一
- **可视化要点**：根部表皮细胞膜上的转运蛋白动画，NO₃⁻ 离子流进入细胞质

### 过程② 根系生长响应 (Root Growth Responses)
- **关键基因**：ZmANR1, ZmDEFLA, ZmCLEs, ZmCEPRs, ZmARFs, ZmAUX/IAAs
- **生物学意义**：低氮胁迫下根系构型的可塑性改变（增深、增密、增大夹角）
- **可视化要点**：根系分支动态生长动画，局部生长素梯度示意

### 过程③ 低氮诱导开花 (Low N Induces Flowering)
- **关键基因**：ZmGI, ZmCONZ1, ZmFLC-like, ZmSVPs, ZmFT-like, ZmDELLAs
- **生物学意义**：氮胁迫作为环境信号提前触发生殖生长转换（逃逸策略）
- **可视化要点**：穗部发育进程加速，光周期通路与氮信号交叉点高亮

### 过程④ 氮素再动员 (N Remobilisation)
- **关键基因**：ZmNAPs, ZmSAGs, ZmGS1.1/1.2/1.3, ZmGDH1/2/3/4, ZmASP-GT
- **生物学意义**：衰老叶片中的氮化合物降解并转运至籽粒的过程，决定收获指数
- **可视化要点**：叶片黄化动画 + 韧皮部转运箭头（氨基酸流向穗部）

### 过程⑤ 叶片扩展与分枝 (Leaf Expansion & Branching)
- **关键基因**：ZmGRFs, ZmSPLs, ZmTCPs, ZmKNOXs, ZmSAM-related
- **生物学意义**：氮充足时促进营养生长，扩大光合面积
- **可视化要点**：茎尖分生组织（SAM）活性指示器，叶片展开动态

### 过程⑥ 花青素合成 (Anthocyanosis)
- **关键基因**：ZmmiR165/166, ZmSPL9, ZmPAP1/2, ZmDFR, ZmANS, ZmUFGT
- **生物学意义**：低氮胁迫下的可见表型标记（叶片/茎秆紫红色），与碳氮平衡相关
- **可视化要点**：代谢通路节点从苯丙氨酸到花青素的逐步合成动画
